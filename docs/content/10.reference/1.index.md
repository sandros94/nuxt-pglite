The `pglite` key of `nuxt.config.ts` takes any part of this shape, merged over the defaults. The type is exported as `ModuleOptions` from `nuxt-pglite`; `ResolvedModuleOptions` is the same with every default filled in.

```ts [defaults]
export default defineNuxtConfig({
  pglite: {
    server: {
      enabled: true,
      config: 'server/pglite.config',
      options: {},
      eager: false,
      socket: false,
    },
    client: {
      enabled: false,
      config: 'app/pglite.config',
      options: {},
      eager: false,
    },
    devtools: {
      enabled: true,
      actions: [],
    },
  },
})
```

## `server`

| Key | Type | Default | |
| --- | --- | --- | --- |
| `enabled` | `boolean` | `true` | Registers `usePGlite()` and the server instance. `false` keeps PGlite out of the server bundle. |
| `config` | `string` | `'server/pglite.config'` | Config file path, relative to the root directory, extension optional. |
| `options` | `SerializablePGliteOptions` | `{}` | Build-time PGlite options the config file can override. A relative `dataDir` is resolved from the root directory; `.data/pglite` when unset. |
| `eager` | `boolean` | `false` | Creates the instance when the server starts instead of on first use. |
| `socket` | `boolean \| SocketOptions` | `false` | Serves the instance over the Postgres wire protocol in `nuxt dev`. |

`SerializablePGliteOptions` is PGlite's `PGliteOptions` without `extensions`, `fs`, `loadDataDir`, `parsers` and `serializers`, which cannot be serialized into the build.

### `server.socket`

| Key | Type | Default | |
| --- | --- | --- | --- |
| `host` | `string` | `'127.0.0.1'` | Interface to bind. |
| `port` | `number` | a free port | Port to bind. |
| `path` | `string` | | Directory for a Unix socket; takes precedence over `host`. Relative to the root directory. |
| `env` | `string \| false \| SocketEnv` | `'DATABASE_URL'` | [Variables exported](/socket#environment-variables), each only while unset: a name for the URL, a map of names to strings or functions of the URL, or `false` for none. |
| `provider` | `SocketProvider` | | A host's [database variables](/socket#provider-presets) in place of `DATABASE_URL` (`'netlify'`); `env` is merged over them. |
| `maxConnections` | `number` | unlimited | Concurrent clients allowed. |
| `idleInTransactionTimeout` | `number` | `0` | Milliseconds a client may sit idle inside a transaction before it is disconnected; `0` disables it. |

## `client`

| Key | Type | Default | |
| --- | --- | --- | --- |
| `enabled` | `boolean` | `false` | Registers the in-browser instance, `usePGlite()` and the live-query composables. Requires the Vite builder. |
| `config` | `string` | `'app/pglite.config'` | Config file path, relative to the root directory, extension optional. |
| `options` | `SerializablePGliteWorkerOptions` | `{}` | Build-time PGlite worker options the config file can override. |
| `eager` | `boolean` | `false` | Starts the worker when the app loads instead of on first use. |

## `devtools`

| Key | Type | Default | |
| --- | --- | --- | --- |
| `enabled` | `boolean` | `true` | Adds the PGlite tab to Nuxt DevTools, when DevTools is enabled. |
| `actions` | `PGliteProcessAction[]` | `[]` | [`process` actions](/devtools/actions#process-actions). Other modules add theirs through the `pglite:devtools:actions` hook. |

Nothing under `devtools` is registered outside `nuxt dev`.
