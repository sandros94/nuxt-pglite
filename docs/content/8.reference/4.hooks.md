Both hooks exist in `nuxt dev` only and are typed on `NuxtHooks` once the module is installed.

## `pglite:devtools:actions`

```ts
(actions: PGliteProcessAction[]) => HookResult
```

Called once every module is set up, with the `process` actions from `nuxt.config.ts`. Push yours to the array:

```ts
nuxt.hook('pglite:devtools:actions', (actions) => {
  actions.push({ id: 'my-module:studio', label: 'Open the studio', run: () => {} })
})
```

Ids must be unique among `process` actions; a duplicate fails the startup.

## `pglite:devtools:prompt`

```ts
() => HookResult
```

Opens the [action picker](/devtools/terminal#the-action-picker) in the `nuxt dev` terminal. Registered only when the terminal is interactive and there are `server` or `process` actions to pick from.

```ts
await nuxt.callHook('pglite:devtools:prompt')
```
